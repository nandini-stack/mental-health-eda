# Mental Health EDA Project

This project analyzes survey data on mental health using exploratory data analysis.

## Goals
- Understand demographic trends
- Explore relationships between mental health indicators
- Answer questions like:
  - Does stress correlate with past treatment?
  - Are mood swings tied to coping struggles?

## Dataset
Sourced from Kaggle: Mental Health Dataset

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
